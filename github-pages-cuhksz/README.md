# 重生之我在港中深上大学

方嘻嘻创作的非官方校园互动视觉小说，仅供娱乐。

## 发布到 GitHub Pages

1. 登录 GitHub，点击右上角 `+`，选择 `New repository`。
2. 仓库名建议填写 `cuhksz-reborn-game`，可见性选择 `Public`，然后创建仓库。
3. 在新仓库页面选择 `uploading an existing file`。
4. 把本文件夹内的 `index.html`、`.nojekyll` 和 `README.md` 一起上传，点击 `Commit changes`。
5. 打开仓库的 `Settings` → `Pages`。
6. 在 `Build and deployment` 下，将 `Source` 设为 `Deploy from a branch`。
7. Branch 选择 `main`，文件夹选择 `/ (root)`，点击 `Save`。
8. 等待约 1–3 分钟，刷新 Pages 页面。网址通常是：

   `https://你的GitHub用户名.github.io/cuhksz-reborn-game/`

以后更新游戏，只需用新版 `index.html` 替换仓库里的旧文件，GitHub Pages 会自动重新发布。
